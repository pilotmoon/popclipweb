# Submit an Extension

::: info Placeholder
This page is a placeholder. Full instructions for submitting an extension
to the directory are coming soon.
:::

You will be able to submit an extension from a public GitHub repository:
install the PopClip Extensions Directory app on your repository, add a
configuration file, and publish a release. Each submission is reviewed
before it appears, and feedback is posted back to your commit.
